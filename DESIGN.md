## Overview

Маяк ощущается как спокойная радиолаборатория: точный нативный инструмент,
который сначала даёт ясный вывод, а затем открывает доказательства. Визуальная
подпись — функциональная топология с тихим радарным движением и живой краб в
углу. Тон защищающий, но не тревожный; риск, видимость и уверенность никогда не
сливаются в один балл.

## Colors

Холодный светлый холст и белые полупрозрачные поверхности составляют базу.
Глубокий ирис — единственный брендовый акцент и цвет основных действий.
Зелёный, янтарный и красный используются только семантически; коралловый
помечает новое. Текст `ink` применяется для выводов, `ink_soft` для пояснений,
`ink_faint` для метаданных. Тёмная тема сохраняет те же смысловые роли, а не
инвертирует цвета механически.

## Typography

Используется системный стек целевой платформы: SF Pro через `-apple-system` и
`BlinkMacSystemFont` на macOS, Segoe UI на Windows. Display — 30/32, 700, с
плотным трекингом; headline — 18/22, 700; title — 13/16, 650; body — 14/20,
400; технические подписи — 10/12, 750, uppercase с трекингом 0.11em. Числовые
параметры используют tabular numerals. Иерархия строится размером и весом, не
лишними цветами.

## Elevation

Высота атмосферная и сдержанная. Основные поверхности отделяются тонкой
границей; малые интерактивные элементы используют тень 0 1px 2px с 5%
непрозрачности, главный сетевой блок — 0 18px 48px с 8% плюс контактная тень.
Blur допустим только в системной боковой панели. Вложенные секции разделяются
линиями, а не дополнительными карточками.

## Components

- Primary button: ирисовая заливка, белая подпись, радиус 10, ясный
  `focus-visible`; split-часть допускается только для выбора режима проверки.
- Secondary button: прозрачная или белая поверхность, тонкая граница,
  нейтральный текст; hover усиливает поверхность, а не добавляет новый цвет.
- Sidebar navigation: иконка, подпись и необязательный счётчик; активный пункт
  получает белую поверхность и ирисовую иконку.
- Status pill: текст плюс иконка, форма capsule, семантический цвет дублируется
  словом или символом.
- Network hero: один крупный вывод слева и функциональная топология справа;
  технические метрики раскрываются ниже.
- Device row: название и тип впереди, затем IP, производитель, доверие и
  доказательства; детали открываются без потери контекста списка.
- Mascot: оригинальный краб Rust живёт в нижнем углу и меняет состояние
  `idle`, `peek`, `scuttle`, `scan`, `wave`, `concerned`; не перекрывает
  управление и отключает движение при Reduced Motion.

## Platform behavior

Композиция, визуальная иерархия и терминология одинаковы на macOS и Windows.
Различия допускаются только там, где они следуют системным соглашениям:
типографика, окно, системные настройки, запросы разрешений и формат установщика.
Интерфейс не должен показывать macOS-термины на Windows или обещать метрику,
которую системный API платформы не предоставил.

## Do's and Don'ts

Делать: сначала показывать вывод; подписывать причину и уверенность; сохранять
полные сетевые факты; различать состояния не только цветом; давать клавиатурный
focus; адаптировать компоновку при ширине 1050 px; уважать Reduced Motion.

Не делать: использовать кислотный неон, терминальную «хакерскую» эстетику,
декоративные графики, стену одинаковых карточек, категоричные обещания
безопасности или отсутствия камер, скрывать ограничения сети, смешивать риск с
полнотой наблюдения, добавлять новые акцентные цвета без семантической роли.
