# История изменений

Значимые изменения проекта перечисляются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версия проекта
следует Semantic Versioning.

## [Unreleased]

### Добавлено

- безопасная автоматическая проверка обновлений при запуске и раз в шесть
  часов с ручным подтверждением установки;
- экран версии, release notes, прогресса загрузки, установки и перезапуска;
- обязательная minisign-проверка updater-пакетов по публичному ключу,
  встроенному в приложение;
- подписанные macOS, NSIS и MSI update-артефакты и проверяемый `latest.json`;
- release pipeline с черновиком до завершения обеих платформ, валидацией
  манифеста, SHA-256 и публикацией только полного релиза.
- офлайн-справочник из публичных IEEE MA-L, MA-M и MA-S для определения
  производителя без внешних запросов;
- динамическое перечисление DNS-SD-сервисов и сохранение безопасных
  TXT-метаданных вместо короткого жёсткого списка Bonjour-протоколов.
- английский интерфейс: язык по умолчанию следует системе и переключается
  в настройках; на выбранном языке выводятся находки, имена устройств, ход
  проверки, ошибки, уведомления, меню в строке состояния, а на macOS — имя
  приложения и системные запросы разрешений.

### Изменено

- версия следующего выпуска повышена до 0.3.0;
- release workflow использует закреплённый commit официального Tauri Action;
- Windows PR CI параллелит lint и тесты, переиспользует Rust-артефакты и
  быстрый debug installer smoke, сохраняя полноценную release-сборку после
  слияния в `main`;
- будущие updater-релизы публикуются как обычные GitHub Releases, чтобы
  стабильный HTTPS endpoint `/releases/latest/` всегда указывал на полный
  подписанный манифест.
- имена и типы устройств выбираются по качеству доказательств: модель
  роутера из SSDP, осмысленное Bonjour-имя, производитель IEEE и только затем
  общий тип.

### Исправлено

- checksum-файлы Windows-релизов записываются в UTF-8 без BOM с переносами LF
  и одинаково проверяются на macOS, Linux и Windows.
- короткие октеты MAC из macOS `arp` нормализуются с ведущим нулём, поэтому
  IEEE-производитель больше не теряется;
- IP-адрес из SSDP `LOCATION` больше не перекрывает человекочитаемую модель
  роутера.

## [0.2.0] — 2026-07-29

### Добавлено

- нативная поддержка 64-битных Windows 10/11 через Windows Native Wi-Fi,
  IP Helper, Winsock, Registry и системные настройки;
- определение текущего Wi‑Fi-подключения, адаптера, шлюза, DNS, соседей,
  прокси, VPN-признаков и локальных имён на Windows;
- платформенный слой, сохраняющий существующую интеграцию macOS через
  CoreWLAN/CoreLocation и системные утилиты;
- Windows-установщики NSIS setup.exe и MSI вместе с DMG для Apple Silicon;
- отдельные CI-проверки macOS и Windows и автоматическая публикация
  установщиков с SHA-256 в GitHub Releases;
- документация по различиям платформ, установке и проверке релизов.

### Изменено

- интерфейс и системные сообщения больше не предполагают, что приложение
  запущено только на Mac;
- локальное устройство получает MAC-адрес через нативный платформенный слой;
- каталог SQLite создаётся с платформенно-корректными правами доступа;
- обновлена уязвимая транзитивная зависимость `serde_with`.

## [0.1.4] — 2026-07-29

### Добавлено

- получение локальных имён устройств через DNS, Bonjour/mDNS, SSDP и SMB;
- карточки устройств с наблюдаемыми доказательствами и уровнем уверенности;
- центрированный радар обнаружения с объяснённой семантикой радиуса;
- анимированный маскот-краб;
- open-source документация, политика приватности и GitHub CI.

### Исправлено

- статус «Новое» снимается сразу после отметки устройства знакомым, своим или
  игнорируемым;
- доверие не теряется при изменении доступности SSID/BSSID;
- исправлено отображение иконки приложения;
- улучшено расположение устройств и анимация сканирования.
