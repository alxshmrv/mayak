# Приватность

Маяк спроектирован как локальное приложение. Для его работы не нужен аккаунт,
а результаты проверки сети не отправляются разработчикам или сторонним
сервисам.

## Какие данные обрабатываются

В зависимости от системных разрешений и доступности сетевых сигналов приложение
может обрабатывать:

- SSID и BSSID текущей Wi‑Fi-сети;
- локальные IP- и MAC-адреса;
- параметры подключения, шлюз, DNS, прокси и признаки VPN;
- имена, сервисы и ответы устройств в текущей локальной подсети;
- отметки пользователя «моё», «знакомое» и «игнорировать»;
- время первого и последнего локального наблюдения устройства;
- настройки мониторинга и уведомлений.

## Где хранятся данные

Данные сохраняются в локальной базе `mayak.sqlite3` в стандартном каталоге
данных приложения с идентификатором `app.mayak.network`:

- macOS: `~/Library/Application Support/app.mayak.network/mayak.sqlite3`;
- Windows: `%APPDATA%\app.mayak.network\mayak.sqlite3`.

На macOS приложение создаёт свой каталог с правами `0700`. На Windows доступ
наследуется от ACL пользовательского каталога `%APPDATA%`.

## Сетевой обмен

Маяк не использует облачный backend, телеметрию, аналитику или рекламные SDK.
Сетевой обмен ограничен текущей локальной подсетью и стандартными локальными
механизмами обнаружения: ARP, DNS/mDNS, SSDP/UPnP, ONVIF и ограниченные
TCP-подключения к диагностическим портам.

Локальные имена разрешаются средствами операционной системы и объявлениями
самих устройств. Производитель определяется офлайн по встроенному снимку
публичных реестров IEEE MA-L, MA-M и MA-S. Приложение не передаёт IP- или
MAC-адреса внешним базам производителей.

Начиная с версии 0.3.0 приложение загружает публичный `latest.json` из GitHub
Releases через HTTPS: один раз после запуска и затем не чаще одного раза в
шесть часов. Запрос не содержит SSID, BSSID, IP, MAC, историю, настройки или
сведения об устройствах. Как и при любом HTTPS-запросе, GitHub может видеть
обычные сетевые метаданные соединения, например внешний IP и User-Agent.

Если доступна новая версия, Маяк показывает описание выпуска. Сам пакет
загружается только после нажатия пользователем кнопки установки. Его подпись
проверяется локально до изменения приложения. Телеметрия об успешной проверке
или установке не отправляется.

## Системные разрешения

- На macOS доступ к геопозиции может требоваться CoreWLAN для SSID/BSSID; на
  Windows 11 24H2 и новее тот же доступ может требовать Windows Native Wi-Fi.
  Маяк не запрашивает и не сохраняет координаты.
- На macOS система отдельно контролирует доступ к локальной сети. На Windows
  доступность локальных ответов также зависит от профиля сети и правил
  Windows Defender Firewall.
- Уведомления нужны только для включённых пользователем локальных оповещений.

## Отчёты об ошибках

Не прикладывайте к публичным issues необработанные скриншоты, логи или базы
данных: они могут содержать SSID, BSSID, IP, MAC и имена устройств. Перед
публикацией замените такие значения тестовыми.

## Удаление данных

Удаление приложения не гарантирует удаление истории. Для полного сброса
закройте Маяк, удалите указанный выше каталог `app.mayak.network` и только
потом при необходимости удалите приложение. Не удаляйте весь `Application
Support` или `%APPDATA%`.

Изменения этой политики отслеживаются в истории Git. Вопросы о приватности
можно обсуждать в GitHub Discussions или issue без добавления чувствительных
сетевых данных.
