# Маяк

[![CI](https://github.com/alxshmrv/mayak/actions/workflows/ci.yml/badge.svg)](https://github.com/alxshmrv/mayak/actions/workflows/ci.yml)
[![macOS 15+](https://img.shields.io/badge/macOS-15%2B-111318?logo=apple)](https://github.com/alxshmrv/mayak)
[![Rust 1.88+](https://img.shields.io/badge/Rust-1.88%2B-dea584?logo=rust)](https://www.rust-lang.org/)
[![License: MIT](https://img.shields.io/badge/license-MIT-786ee8.svg)](LICENSE)

Локальный центр доверия к Wi‑Fi для macOS. Маяк объясняет состояние текущей
сети, показывает наблюдаемые устройства и помогает заметить новых соседей —
без аккаунта, облака и отправки сетевых данных наружу.

Системная часть написана на Rust и Tauri 2, интерфейс — на React.

![Обзор сети в Маяке](docs/images/overview.png)

> Используйте Маяк только в сетях, которыми вы владеете, управляете или имеете
> явное разрешение проверять. Приложение предназначено для защитной
> диагностики: оно не подбирает пароли, не эксплуатирует устройства и не
> обходит контроль доступа.

## Возможности

- SSID, BSSID, защита, канал, диапазон, RSSI, шум и скорость соединения;
- IP-адреса, подсеть, шлюз, DNS, прокси и признаки активного VPN;
- обнаружение через ARP, mDNS, SSDP/UPnP, ONVIF и ограниченные TCP-проверки
  только в текущей локальной подсети;
- объединение IP, MAC, производителя, локальных имён, сервисов, портов и
  наблюдений в одну карточку устройства;
- понятные статусы «моё», «знакомое», «игнорировать» и уведомления о новых
  устройствах;
- отдельные оценки риска сети, полноты наблюдения и уверенности вывода;
- локальная история для каждой сети и фоновый мониторинг;
- явное различие между подтверждённой и возможной камерой;
- анимированный маскот — краб Ferris, который реагирует на состояние проверки.

![Список видимых устройств](docs/images/devices.png)

Имена устройств появляются только тогда, когда сеть или само устройство
объявляет их через локальный DNS, Bonjour/mDNS, SSDP или SMB. Если надёжного
имени нет, Маяк показывает наблюдаемые адреса и уровень уверенности, не
выдумывая производителя или тип устройства.

## Честные ограничения

Маяк показывает только то, что Mac действительно может наблюдать. Client
isolation в отеле, отдельные VLAN, фильтрация multicast, спящие устройства,
межсетевой экран и рандомизация MAC могут скрыть соседей или изменить их
идентичность. Отсутствие найденной камеры не доказывает отсутствие камеры в
помещении или сети.

Радар в интерфейсе — визуализация процесса обнаружения. Радиус означает
уверенность в классификации устройства, а не физическое расстояние до него.

## Установка и статус релиза

Сейчас проект публикуется как open-source beta для Apple Silicon и macOS 15+.
Готовый публичный бинарник пока не распространяется: локальные сборки
подписываются ad-hoc и не нотариализованы Apple. Для безопасной установки
соберите приложение из исходников.

Требования:

- macOS 15 или новее;
- Apple Silicon;
- Xcode Command Line Tools;
- Rust 1.88 или новее;
- Node.js 22.12 или новее.

```bash
git clone https://github.com/alxshmrv/mayak.git
cd mayak
npm ci
npm run tauri build
```

Готовое приложение и DMG появятся в `src-tauri/target/release/bundle/`.

## Разработка

```bash
npm ci
npm run check
cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --all-targets
npm run tauri dev
```

GitHub Actions выполняет те же основные проверки на macOS. Правила работы с
проектом описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Приватность и разрешения macOS

Все результаты хранятся локально в SQLite внутри стандартного каталога
Application Support приложения. Маяк не содержит телеметрии, аналитики,
рекламных SDK или облачного API. Подробности — в [PRIVACY.md](PRIVACY.md).

- **Геопозиция** необязательна и нужна macOS только для раскрытия имени Wi‑Fi
  и BSSID. Географические координаты приложение не получает и не сохраняет.
- **Локальная сеть** нужна для обнаружения соседних устройств.
- **Уведомления** запрашиваются только после включения соответствующих
  переключателей в настройках.

## Архитектура

```text
React UI
  └─ типизированные Tauri-команды и события
      ├─ контекст сети (CoreWLAN/CoreLocation + системные утилиты macOS)
      ├─ движок обнаружения (ARP, mDNS, SSDP, ONVIF, bounded TCP)
      ├─ fingerprinting + объяснимая оценка риска
      └─ SQLite: история, доверие к устройствам и настройки
```

Сканер ограничивает число одновременных соединений, привязывает multicast и
ONVIF-сокеты к Wi‑Fi-интерфейсу и не выходит за границы текущей локальной
подсети.
