# Кодекс поведения

Мы хотим, чтобы работа над Маяком оставалась безопасной, доброжелательной и
профессиональной для людей с любым уровнем опыта.

Ожидается:

- уважительное обсуждение идей и кода;
- конкретная, технически обоснованная обратная связь;
- бережное отношение к приватности и безопасности других людей;
- признание ошибок и готовность исправлять их;
- отсутствие дискриминации, травли, угроз и публикации чужих личных данных.

Недопустимое поведение может привести к удалению материалов, временному
ограничению участия или блокировке. Сообщить о проблеме можно владельцу
репозитория через приватный GitHub security advisory. Не используйте публичный
issue, если обращение содержит личные или чувствительные сведения.

Этот кодекс действует в репозитории, issue, pull request и других официальных
пространствах проекта.
