# Поддержка платформ

Маяк использует один Rust-домен, движок обнаружения, SQLite-хранилище и React
интерфейс на macOS и Windows. Платформенный слой отвечает только за сведения,
которые операционные системы предоставляют разными API.

## Поддерживаемые системы

| Платформа | Архитектура | Версия | Статус |
| --- | --- | --- | --- |
| macOS | arm64, Apple Silicon | macOS 15+ | Поддерживается |
| Windows | x64 | Windows 10/11 | Поддерживается |
| macOS Intel | x86_64 | — | Готового релиза нет |
| Windows ARM | arm64 | — | Готового релиза нет |
| Linux | — | — | Не поддерживается |

## Матрица возможностей

| Возможность | macOS | Windows |
| --- | --- | --- |
| SSID/BSSID и состояние Wi‑Fi | CoreWLAN/CoreLocation | Windows Native Wi-Fi |
| Защита, PHY, RSSI, канал, скорость | Да | Да |
| Шум, код страны, ширина канала | Если раскрывает CoreWLAN | Могут быть недоступны |
| IPv4/IPv6, маска, интерфейс | Системные интерфейсы | IP Helper и системные интерфейсы |
| Шлюз и DNS | `route`, `scutil` | IP Helper |
| Таблица соседей | ARP | `GetIpNetTable2` |
| Локальные имена | системный DNS/mDNS | Winsock DNS/mDNS |
| mDNS, SSDP, ONVIF, bounded TCP | Да | Да |
| История, доверие, риск, мониторинг | Да | Да |
| Локальные уведомления | Да | Да |
| Открытие системных настроек | System Settings | Windows Settings |

Если системный API не предоставил метрику, Маяк показывает её как
неопределённую. Значения не вычисляются и не подменяются для визуального
совпадения платформ.

## Разрешения

### macOS

- **Local Network** нужен для ответов устройств в локальной подсети.
- **Location Services** может быть нужен CoreWLAN для SSID и BSSID.
- **Notifications** запрашиваются только после включения оповещений.

### Windows

- На Windows 11 24H2+ **Location** может быть нужен Native Wi-Fi для SSID и
  BSSID.
- Видимость соседей зависит от профиля сети, client isolation и правил
  Windows Defender Firewall.
- **Notifications** запрашиваются только после включения оповещений.

Ни одна платформа не передаёт Маяку географические координаты.

## Общие ограничения

Обе реализации видят только текущий L2/L3-сегмент. Client isolation в отеле,
VLAN, фильтрация multicast, спящие устройства, firewall и рандомизация MAC
могут скрыть устройство или изменить его наблюдаемую идентичность. Найденные
порты и протоколы являются признаками, а не доказательством владельца или
физического расположения устройства.

GitHub Actions компилирует, тестирует и упаковывает обе платформы. Проверки,
зависящие от конкретного Wi‑Fi-чипсета, версии драйвера и политики сети,
дополнительно требуют smoke-теста на реальном компьютере.
