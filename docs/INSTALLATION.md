# Установка Маяка

Маяк распространяется как open-source beta для Apple Silicon/macOS 15+ и
64-битных Windows 10/11. Готовые установщики находятся только в
[GitHub Releases](https://github.com/alxshmrv/mayak/releases).

## Какой файл выбрать

| Система | Файл | Назначение |
| --- | --- | --- |
| macOS, Apple Silicon | `Mayak-<версия>-macos-arm64.dmg` | Обычная установка на Mac |
| Windows x64 | `Mayak-<версия>-windows-x64-setup.exe` | Рекомендуемая установка для текущего пользователя |
| Windows x64 | `Mayak-<версия>-windows-x64.msi` | Ручное или корпоративное развёртывание |

Архивы `Source code`, которые GitHub добавляет автоматически, не являются
установщиками.

## macOS

1. Скачайте DMG и соседний файл `.dmg.sha256` из одного релиза.
2. Проверьте SHA-256:

   ```bash
   shasum -a 256 -c Mayak-0.2.0-macos-arm64.dmg.sha256
   ```

3. Откройте DMG и перенесите `Маяк.app` в `Applications`.
4. Запустите приложение. Поскольку beta пока не нотариализована Apple,
   Gatekeeper может показать предупреждение. Убедитесь, что файл скачан из
   `alxshmrv/mayak`, затем используйте **System Settings → Privacy & Security
   → Open Anyway**.
5. Разрешите локальную сеть. Геопозиция нужна только для раскрытия SSID/BSSID;
   координаты приложение не получает.

Текущий DMG поддерживает только Apple Silicon. Intel Mac пока не поддерживается.

## Windows

1. Скачайте setup.exe и соседний файл `.exe.sha256` из одного релиза.
2. В PowerShell сравните хэши:

   ```powershell
   (Get-FileHash .\Mayak-0.2.0-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLower()
   Get-Content .\Mayak-0.2.0-windows-x64-setup.exe.sha256
   ```

   Первые 64 символа должны совпасть.

3. Запустите setup.exe. Он устанавливает Маяк для текущего пользователя и не
   требует системного развёртывания.
4. Пока beta не подписана Microsoft, SmartScreen может показать
   предупреждение. Продолжайте только после проверки источника и SHA-256.
5. Если WebView2 Runtime отсутствует, установите его с официального сайта
   Microsoft и повторите запуск.
6. Разрешение геопозиции может понадобиться Windows 11 24H2+ для чтения
   SSID/BSSID. Маяк не получает координаты.

MSI содержит ту же x64-версию приложения и предназначен прежде всего для
администраторов или управляемого развёртывания.

## Обновление

Маяк пока не обновляется автоматически. Закройте приложение, скачайте
установщик новой версии из Releases, проверьте SHA-256 и установите поверх
текущей версии. Локальная история и доверие сохраняются в каталоге данных.

## Удаление

Удалите приложение обычным способом:

- macOS: удалите `Маяк.app` из `Applications`;
- Windows: **Settings → Apps → Installed apps → Маяк → Uninstall**.

История не удаляется автоматически. Для полного сброса после закрытия
приложения удалите только его каталог:

- macOS: `~/Library/Application Support/app.mayak.network`;
- Windows: `%APPDATA%\app.mayak.network`.

Не удаляйте целиком `Application Support` или `%APPDATA%`.
